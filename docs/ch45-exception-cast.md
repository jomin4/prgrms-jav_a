## 🎯 핵심 개념
- 자바는 위험하다고 판단되면 개발자의 사인을 필요로 한다. 단 막 사인하면 실행 중 오류인 익셉션이 발생한다.
- 자바에서는 안전하다고 판단되면 자동형변환을 해준다.
- 자바에서는 위험하다고 판단되면 수동형변환을 요구한다.
- 자바의 객체의 메서드 호출은 항상 원격호출이다. 그래서 리모콘 버튼에 목숨을 건다.
- 리모콘의 버튼 개수가 늘리는 행위 : 편해지지만 위험
- 추가되는 버튼에 대응되는 기능이 해당 리모콘과 연결 되어있는 객체에 없을 수 도 있기 때문
- 리모콘의 버튼 개수가 줄이는 행위 : 불편해지지만 안전
- 버튼을 제거하는 행위 자체는 그 어떠한 위험도 초래하지 않음
- 자동형변환과 수동형변환
- 흐름상 형변환이 안되는데도 무리하게 사인수동형변환을 하면 고객이 오류를 겪는다.즉 런타임 오류 발생
