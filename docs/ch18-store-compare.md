# 18강 · 인스턴스 변수가 아닌 지역 변수기준으로 기본형 변수와 레퍼런스 변수의 저장방식 비교

## 🎯 핵심 개념
- 인스턴스 변수가 아닌 지역 변수기준으로 기본형 변수와 레퍼런스 변수의 저장방식 비교
- 비주얼라이저
- 객체내부에 선언된 변수를 인스턴스변수라고 한다. 이 부분은 추후에 자세히 다룹니다.
- 함수안에서 선언된 변수를 지역변수라고 한다.
- 지역변수는 스택에 저장된다.
- 함수안에서 선언된 기본형 변수는 다음과 같은 특징을 가진다.
- 변수 : 스택에 위치
- 변수의 값 : 스택에 위치
- 함수안에서 선언된 레퍼런스형 변수는 다음과 같은 특징을 가진다.
- 변수의 값 : 실제 값이 아닌 실제 값의 주소값
- 실제 값 : 힙에 저장됨
