# 49강 · 생성자를 직접 만들지 않는다면, 자동으로 인자없는 생성자가 생성된다, 생성자가 호출되면 기본적으로는 자동으로 부모 생성자 호출.

> P10. 생성자 · 출처: [slog.gg/p/14146](https://www.slog.gg/p/14146) 49강

## 🎯 핵심 개념
- 생성자를 직접 만들지 않는다면, 자동으로 인자없는 생성자가 생성된다, 생성자가 호출되면 기본적으로는 자동으로 부모 생성자 호출.
- `new 노루;`에서의 생성자 연쇄호출
- $$uml
- @startuml
- participant "노루 생성자" as 노루
- participant "동물 생성자" as 동물
- participant "Object 생성자" as Object
- 노루 -> 동물: super
- 동물 -> Object: super
- Object -> Object: Object 생성자 작업 수행
- Object --> 동물: 작업종료
- 동물 -> 동물: 동물 생성자 작업 수행
- 동물 --> 노루: 작업종료
- 노루 -> 노루: 노루 생성자 작업 수행
- 노루 -> 노루: 객체 초기화 완료, 리모콘 리턴
- @enduml
- $$
- 생성자 연쇄호출
- `super;` 만으로는 해결이 안되는 경우
