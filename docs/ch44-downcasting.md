## 🎯 핵심 개념
- 하위타입으로의 형변환은 수동형변환이 필수, 수동현변환은 깐깐한 컴파일러를 안심시켜주는 사인이다. 개발자가 책임을 지게 된다.
- 추상적 변환과 구체적 변환
- 추상적 변환 == 안전 == 자동형변환
- 구체적 변환 == 위험 == 수동형변환
- 문제

```java
// 5 -> 5.0
// 추상적으로 변화 == 자동형변환
double d = 5; 

// 5.0 -> 5
// 구체적으로 변화 == 수동형변환 필수
int d = (int)5.0;
```
