# 6강 · 변수는 저장공간으로서 작동할 때도 있고, 값으로서 작동할 때도 있다.

## 🎯 핵심 개념
- 변수는 저장공간으로서 작동할 때도 있고, 값으로서 작동할 때도 있다.
- 보조기억장치와 램, 프로그램과 프로세스
- 보조기억장치는 용량이 크고, 속도가 느리고, 영속성이 있다.
- 램메모리은 용량이 작고, 속도가 빠르고, 영속성이 없다.
- 프로그램은 보조기억장치에 위치한다.
- 프로세스 == 실행중인 프로그램
- 프로세스는 램에 위치한다.
- 하나의 프로그램으로 여러개의 프로세스를 생성할 수 있다.
- 변수는 램에 위치한다.
- 보조기억장치와 램 비교
- | 구분             | 보조기억장치            | 램메모리          |
- |------------------|------------------------|----------------------|
- | 위치            | 컴퓨터 내부             | 컴퓨터 내부           |
- | 저장 용량        | 큼수십 GB ~ 수 TB 이상 | 작음수 GB 내외     |
- | 속도            | 느림                   | 빠름                 |
- | 영속성           | 있음전원 꺼져도 유지됨 | 없음전원 끄면 사라짐 |
- | 사용 목적        | 데이터 영구 저장         | 프로그램/데이터 임시 저장 |
- | 예시             | SSD, HDD, USB 등        | DRAM, SRAM 등         |
- 프로그램과 프로세스 비교
- | 구분         | 프로그램                      | 프로세스                    |
- |--------------|------------------------------|-----------------------------|
- | 정의         | 실행 가능한 파일정적 개념    | 실행 중인 프로그램동적 개념|
- | 저장 위치    | 보조기억장치SSD/HDD 등      | 램메모리                  |
- | 상태         | 비활성정지                  | 활성진행중                |
- | 수량         | 하나파일마다 1개            | 여러 개동일 프로그램도 여러 프로세스|
- | 예시         | 메모장.exe, chrome.exe 등     | 실행 중인 메모장, 크롬 등   |

## 💻 실습 코드 & 실행 결과
`src/ch06-variable/Main.java`

```java
public class Main {
    public static void main(String[] args) {
    	int x; // 변수
        x = 5; // 변수
        x = x + 10; // 좌측 x는 변수, 우측 x는 변수가 아닌 값(5)으로 취급
        
        System.out.println(x + 20); // 여기서의 x는 x가 아닌 15로 취급
    }
}
```

**실행 결과**
```
35
```
